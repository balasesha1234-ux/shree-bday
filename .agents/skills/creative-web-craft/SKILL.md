# Creative Web Craft & Interactive Engineering

This skill provides operational patterns for creating world-class web experiences:

## 1. 3D Camera Viewports & Parallax
- Use `perspective: 1200px` with `transform-style: preserve-3d`.
- Track coordinates on a static wrapper to prevent recursive coordinate feedback.
- Apply subtle chromatic aberration, volumetric god rays, or lens dust for cinematic depth.

## 2. Fluid Canvas Particle Systems
- Render multi-segment kinematic agents (e.g. Koi fish, swimming particles) using sinusoidal spinal wave propagation.
- Combine behavioral AI: Peaceful cruising state, hover proximity curiosity ($<85\text{px}$), and sudden fear darting bursts with liquid splash ripples.

## 3. High-Concurrency Database Sync
- Wire all real-time forms to Supabase tables with Row Level Security (RLS) enabled.
- Protect all forms with invisible honeypots (`<input style="display:none" />`) and sub-400ms submission timing guards.
- Implement Stale-While-Revalidate query caches to absorb 10,000+ simultaneous readers.
